# Sanket Portfolio

A responsive one-page portfolio prepared for GitHub Pages.

## Publish
1. Upload `index.html`, `style.css`, `script.js`, and `CNAME` to the root of the `main` branch.
2. In GitHub open Settings > Pages.
3. Under Build and deployment choose Deploy from a branch, select `main` and `/ (root)`, then Save.
4. In Pages, set the custom domain to `www.bansalsanket.com` if that is the hostname configured with your DNS provider.

## Edit
- Content: `index.html`
- Colors/layout: `style.css`
- Interactions: `script.js`

## Privacy
The site uses only public career content from the existing website. Review all content before publishing and avoid adding confidential employer information.
